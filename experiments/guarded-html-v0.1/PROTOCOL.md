GLM5.3, local Mac/OpenCode, supported low reasoning variant, one generation call,
8seconds/192frames at24fps, same neutral factual/design brief. The model returns
HTML/CSS/SVG/GSAP directly for FrameLang's trusted admission mode; no JSON
conversion or source redesign follows. Every call's tokens/cost remain recorded.

An inherited experimental regex rejected `https://yourproduct.com` appearing as
ordinary visible text, falsely treating it as a network resource. The actual
FrameLang HTML parser correctly distinguishes text from declared references.
The original harness failure, response and charge are preserved. Its unedited
source is separately replayed through the CLI after removing that harness
pre-filter. The replay makes zero further inference calls. Do not call this a
clean controlled cost comparison or conceal the harness failure.

This mode runs trusted code; the package and frame checks are not an untrusted
JavaScript sandbox or a universal deterministic guarantee. Contrast is sampled.
