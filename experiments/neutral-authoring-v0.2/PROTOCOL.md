# Frozen neutral-authoring pilot

Exploratory pilot v0.1 exposed overly restrictive decorative-overlap checks and
prompt defects. Its complete logs and costs remain in its own directory.
This protocol freezes the corrected grammar and compiler before new generation.

Two models: DeepSeek V4.1 Flash and GLM5.3, both supported low reasoning variants.
Both arms share exactly the same factual/design brief, local OpenCode config,
1920x1080 orientation,8seconds at24fps, frozenfont/GSAP and max2attempts.
Both arms receive every-frame geometry and sampledcontrast checks before render.
Order alternates between models; no hand-edited programs or fallback renders.

FrameLang repairs request a small JSON object with a patch array; raw repairs
return complete HTML. First-accepted-video cost sums ALL attempts in that arm.
Exploratory v0.1 and earlier redesign-study costs are separate R&D costs, never
silently erased. Provider usage absent from logs stays unknown.

Render success is an admissibility gate, not a creativity metric. Review actual
renders for coherence, typography, visual metaphor, motion and clutter. No
blanket cost or quality advantage can be inferred from two models or one sample.

## Discovered limitation

The frozen prompt said motion must end8frames before scene end, while the
compiler required a15percent final hold. DeepSeek therefore received an
inconsistent contract and spent a repair call shortening duration without
updating its final keyframe. This pilot is exploratory evidence, not a clean
controlled benchmark. The source, logs and failed attempt costs remain intact.
Compiler changes after the frozen run are evaluated separately as replays.
